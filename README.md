# CTI 情資作業全景

內外部情資蒐集 × 脆弱性識別的動畫簡報網頁，由 Allan 顧問與 AI 助理阿拉蕾串場，供 ISMS 輔導客戶說明使用。

製作：Allan顧問，2027/10/17

## 觀看方式

直接用瀏覽器開啟 `index.html`。檔案已內嵌所有角色圖片，可寄送或離線播放；離線時字型會改用系統字型。

| 操作 | 方式 |
|---|---|
| 自動播放／暫停 | 底部播放鍵，或空白鍵 |
| 上一段／下一段 | ← → 方向鍵，或底部按鈕 |
| 跳到指定段落 | 點底部進度條 |
| 全螢幕 | 右上角按鈕，或 F 鍵 |
| 閱讀模式 | 右上角按鈕；手機會自動進入，所有內容與串場對話一次展開 |

## 內容架構（13 段）

| 段落 | 主題 | 重點 |
|---|---|---|
| 00 | 開場 | Allan 顧問與阿拉蕾登場 |
| 01 | 標準怎麼要求 | ISO/IEC 27001:2022 A.5.7、A.8.8、條文 4.1→9.3；情資三層次與四特性 |
| 02 | 全景架構 | 內部情資、外部情資、脆弱性識別匯入情資融合中心，產出四種行動並回饋 |
| 03 | 情資生命週期 | 規劃、蒐集、處理、分析、分送、回饋 |
| 04 | 內部情資 | 原架構 7 類來源，擴充雲端與 SaaS、人員與郵件通報、供應商通報 |
| 05 | 外部情資 | 政府、ISAC、漏洞知識庫、原廠公告、媒體研究、暗網監控 |
| 06 | 脆弱性識別 | 資產盤點、弱點掃描、網站與 App 檢測、滲透測試、資安健診、原碼檢測、組態檢核、社交工程演練、紅隊演練 |
| 07 | AI 風險排序 | CVSS × 遭利用可能 × 資產重要性 × 曝險程度；P1 至 P4 建議時限 |
| 08 | AI 情資融合 | AI 處理流程、人員覆核、AI 使用守則 |
| 09 | 情資到行動 | 風險矩陣與五級威脅程度對應行動 |
| 10 | 紀錄與稽核 | 每月外部情資彙整、重大漏洞處理表、資安工作月報；稽核員查核重點 |
| 11 | 節奏與成效 | 每日至每年的作業節奏、事件觸發、KPI |
| 12 | 結語 | 看得見、找得到、排得準、做得到、證得出 |

建議頻率、修補時限與 KPI 目標值都是建議值，頁面上已標示，使用時請依客戶的資安責任等級、法規要求與風險調整。風險排序、AI 終端機與紀錄表單中的資料為範例情境。

## 修改與重新建置

```
src/template.html        頁面原始碼（樣式、結構、串場台詞與動畫）
src/sprites/*.webp       角色姿勢與表情圖
src/source/*.jpg         角色設定原圖
tools/crop_sprites.py    從設定原圖裁切並去背，輸出 src/sprites
tools/build.py           把精靈圖內嵌進範本，輸出 index.html
```

修改 `src/template.html` 後執行：

```
python3 tools/build.py
```

- **改台詞**：編輯範本裡的 `SCRIPT` 物件，每行格式為 `[說話者, 表情, 台詞]`。
- **改署名或日期**：範本中「製作：Allan顧問，2027/10/17」共出現三處。
- **重新裁切角色圖**：調整 `tools/crop_sprites.py` 的裁切框後執行 `python3 tools/crop_sprites.py`，需要 Pillow 與 numpy。
